# Prompt 工程

## 核心结构

一个可重复执行的任务提示应明确：目标、输入、约束、输出格式、验收标准、停止条件和审批边界。

## 在个人系统中的应用

- 为 Scheduled Tasks 编写可长期运行的任务说明。
- 为 Skills 固化稳定的工作流程。
- 为 AI装修和 AI内容生产定义结构化输入输出。
