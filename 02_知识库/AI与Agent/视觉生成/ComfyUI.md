# ComfyUI

## 定位

ComfyUI 是个人 AI 系统中的图片和视频生成执行工具，由 Codex 通过工作流文件、API 或授权的电脑操作进行调度。

## 管理对象

- 工作流 JSON
- 模型和 LoRA 清单
- Prompt 模板
- 输入素材与生成结果
- 质量检查记录
