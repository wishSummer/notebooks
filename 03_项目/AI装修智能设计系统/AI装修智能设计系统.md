# AI 装修智能设计系统

## 目标

建立面向装修公司和设计工作室的方案辅助与获客系统，将客户资料整理、方案草稿、效果图候选、报价项和反馈复盘串成闭环。

## 当前状态

`规划中`

## 30 天里程碑

- [ ] 定义标准需求问卷。
- [ ] 建立一个真实户型案例。
- [ ] 生成空间方案和报价项草稿。
- [ ] 通过 ComfyUI 生成至少 3 张效果图候选。
- [ ] 完成人工审核后的方案册草稿。

## 验收标准

使用一套真实资料，完整走通“需求整理 → 方案草稿 → 效果图 → 报价项 → 人工审核”。
