# AI 装修智能设计系统

## 目标

建立面向装修公司和设计工作室的方案辅助与获客系统，将客户资料整理、方案草稿、效果图候选、报价项和反馈复盘串成闭环。
根据客户需求、户型图纸、毛坯现场图片等内容，生成设计效果图。

## 当前状态

`规划中`

## 30 天里程碑

- [ ] 确认所需提供的需求项。
- [ ] 模拟需求案例。
- [ ] 创建comfyui workflow。
- [ ] 通过 ComfyUI 生成至少 3 张效果图候选。
- [ ] 完成人工审核后的方案册草稿。

## 验收标准

使用一套真实资料，完整走通“需求整理 → 方案草稿 → 效果图  → 人工审核”。
