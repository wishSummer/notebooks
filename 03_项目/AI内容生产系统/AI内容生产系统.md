# AI 内容生产系统

## 目标

建立从选题、研究、脚本、分镜、视觉素材到发布复盘的内容生产流程，由 Codex 负责协调与沉淀，专业工具负责媒体生成。

## 当前状态

`规划中`

## 30 天里程碑

- [ ] 确定一个目标受众和内容方向。
- [ ] 建立选题与研究模板。
- [ ] 生成 3 个完整脚本和分镜。
- [ ] 通过 ComfyUI 生成一组视觉素材。
- [ ] 使用 FFmpeg 完成一个视频样片。

## 验收标准

完整走通一次“选题 → 研究 → 脚本 → 分镜 → 素材 → 合成 → 人工审核 → 复盘”。
